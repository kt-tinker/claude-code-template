# コードスタイル

- フォーマットは Prettier、Lint は ESLint の設定に従う。スタイルの議論より設定を優先する
- インデントは 2 スペース、文字列はシングルクォート、セミコロンあり
- `any` は使わない。やむを得ない場合は `unknown` にして型ガードで絞り込む
- 関数は named export を使う。default export はフレームワークが要求する場所だけ
- 命名: 変数・関数は camelCase、型・クラス・コンポーネントは PascalCase、定数は UPPER_SNAKE_CASE
- ファイル名は kebab-case（React コンポーネントのみ PascalCase）
- 1 関数はおおむね 50 行以内。長くなったら分割する
- 早期 return でネストを浅くする
- コメントは「なぜ」を書く。「何をしているか」はコードで表現する
- 使われていないコード・import・コメントアウトしたコードは残さない
- 新しい依存パッケージを追加する前に、既存の依存や標準ライブラリで足りないか確認し、追加する理由を説明する
