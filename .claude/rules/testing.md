# テスト

- テストフレームワーク: Vitest（ユニット）、Playwright（E2E）
- テストファイルは `tests/` に `src/` と同じ構成で置く（例: `src/lib/price.ts` → `tests/lib/price.test.ts`）
- 1 テスト 1 観点。テスト名は「〜のとき〜になる」形式で、日本語で書いてよい
- Arrange / Act / Assert の順で書き、空行で区切る
- 外部 API・時刻・乱数はモックする。実際のネットワークにアクセスしない
- テストを通すために実装側のテストを弱めたり、`skip` / `only` を残したりしない
- バグ修正では、まず失敗するテストを書いて再現させてから修正する
- 実行は対象ファイルを指定する（`npm test -- tests/lib/price.test.ts`）。全件実行は最後に一度だけ
- カバレッジの数字のためだけのテストは書かない。振る舞いを検証する
