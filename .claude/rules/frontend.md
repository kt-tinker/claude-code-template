# フロントエンド

- コンポーネントは関数コンポーネント + hooks。クラスコンポーネントは使わない
- 既存のコンポーネント（`src/components/ui/`）を先に探し、なければ新規作成する
- スタイルは <Tailwind CSS / CSS Modules など> に統一する。インラインスタイルは使わない
- 状態はできるだけ使う場所の近くに置く。グローバル状態は本当に必要なときだけ
- アクセシビリティ: 画像には `alt`、ボタンには意味のあるラベル、フォーム要素には `label` を付ける
- 色・余白・フォントサイズはデザイントークン（`src/styles/tokens`）を使い、値を直接書かない
- UI を変更したら、可能であれば Playwright MCP でブラウザ表示を確認する
