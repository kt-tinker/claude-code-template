# src/api — API ハンドラ

このディレクトリ配下のファイルを扱うときに読み込まれる指示です。

- ハンドラは 1 ファイル 1 エンドポイント。ファイル名はルートに合わせる（例: `users.get.ts`）
- 入力は必ず zod スキーマで検証してから使う。スキーマは `src/api/schemas/` に置く
- ビジネスロジックはハンドラに書かず `src/lib/` のサービス関数を呼ぶ
- エラーは `src/api/errors.ts` の `ApiError` を投げる。生の `Error` やスタックトレースをレスポンスに含めない
- レスポンス形式: 成功 `{ data: ... }`、失敗 `{ error: { code, message } }`
- 新しいエンドポイントを追加したら `docs/api.md` も更新する
