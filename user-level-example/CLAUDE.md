# 個人の共通設定（~/.claude/CLAUDE.md に置く。全プロジェクトで読み込まれる）

ここにはどのプロジェクトでも変わらない好みだけを書く。プロジェクト固有の内容は各リポジトリの CLAUDE.md に書く。

## コミュニケーション

- 日本語で回答する。コード中のコメントとコミットメッセージは各プロジェクトの規約に従う
- 結論から書き、前置きは省く
- 不明点や複数の解釈があるときは、推測で進めずに質問する
- 自信がないこと、検証していないことはそう明記する

## 作業の進め方

- 大きな変更の前に、方針を箇条書きで示してから着手する
- 変更後は、何を変えたか・どう確認したかを短く報告する
- 依頼されていないリファクタリングやファイル追加はしない

## Git

- コミットは Conventional Commits 形式
- push・force push・ブランチ削除は必ず確認をとってから行う
